**Risk-Adjusted Portfolio Analysis using Python**

A Python-based finance analytics project focused on portfolio analysis, risk assessment, and investment optimization using historical market data. This project demonstrates how data analysis and financial concepts can be combined to evaluate investment performance and build a diversified portfolio strategy.

---


**Project Overview**

This project analyzes historical stock market data to:

- Evaluate company-wise investment performance
- Calculate returns and volatility
- Compare risk vs return across multiple companies
- Build a low-risk optimized portfolio
- Simulate portfolio allocation strategies
- Visualize investment growth and performance trends

The project is built using Python and commonly used data analysis libraries.

--- 

**Features**

- Historical stock price analysis
- Return on Investment (ROI) calculation
- Volatility and risk analysis
- Portfolio allocation using inverse volatility weighting
- Investment growth comparison
- Data visualization using charts and graphs
- Portfolio performance evaluation

**Project Workflow**

1. Import and clean stock market data
2. Analyze company-wise historical performance
3. Calculate daily/monthly returns
4. Measure portfolio volatility
5. Identify low-risk investment options
6. Allocate investment weights using inverse volatility
7. Visualize portfolio performance
